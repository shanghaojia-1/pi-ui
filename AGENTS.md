# Repository instructions for AI agents

When creating, extending, or reviewing an application theme, read and follow
[`docs/THEME_DEVELOPMENT.md`](docs/THEME_DEVELOPMENT.md) before editing code or
processing image assets.

Do not treat a portrait theme as a palette-only change. Preserve the base
layout and interaction contracts documented there, theme the complete product,
and run the required validation checklist before handing the work back.
